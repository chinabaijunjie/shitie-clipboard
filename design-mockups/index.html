① 深色毛玻璃

Raycast / Spotlight 风格。深灰蓝半透明背景 + 强模糊 + 半透明选中胶囊。剪贴板工具的经典质感,沉浸感强。

规划默认方向

② 浅色系统

macOS 系统设置 / iOS 风格。浅灰白底 + 分组卡片 + 蓝色强调。清爽明亮,长时间使用不压抑,辨识度高。

清爽明亮

③ 深灰折中

介于深浅之间。中性深灰 + 微弱毛玻璃 + 暖色强调。比纯深色温和,比浅色有质感,兼顾白天黑夜使用。

温和折中
